# ResearchThread 种子测试手册（Windows x64 · 0.1.0 Seed）

感谢参与种子测试。这份手册说明怎么装、数据放在哪、怎么保护数据、以及反馈时我们收集什么、**不**收集什么。

## 1. 安装

1. 下载 `ResearchThread_0.1.0_x64-setup.exe`（注意核对下载页公布的 SHA-256 校验值，可在 PowerShell 用
   `Get-FileHash .\ResearchThread_0.1.0_x64-setup.exe` 比对）。
2. 双击运行。安装器未做代码签名，Windows SmartScreen 可能弹出「Windows 已保护你的电脑」——
   这是预期行为，**不需要关闭 SmartScreen**：点「更多信息」→「仍要运行」即可。
3. 按用户安装（默认），不需要管理员权限。应用装在 `%LOCALAPPDATA%\ResearchThread`。

## 2. 数据在哪里，卸载会发生什么

- 你的全部笔记数据（空间 / 项目 / 任务 / 上下文日志 / 周文档）都是 **本机 Markdown 文件**，存放在
  `C:\Users\<你>\ResearchThread\`（下称「数据目录」），可以随时用记事本或 Obsidian 打开。
- **卸载应用不会删除数据目录**。卸载只移除程序本体与应用界面设置（主题、布局偏好等）；
  重新安装后数据原样回来。
- 建议偶尔把整个数据目录复制到别处（或网盘 / 移动硬盘）作为额外备份。

## 3. 版本保护（快照）

- 数据目录内置 git 版本历史：**每天第一次启动会自动提交一次快照**，也可以在
  「设置 → 数据 → 创建 git 快照」手动快照。
- 快照依赖系统安装的 git。若你的电脑没有 git（或 git 不在 PATH），应用启动时会在左下角显示
  「快照保护未生效」的持续警告——数据仍然正常保存，但没有版本历史兜底。安装
  [Git for Windows](https://git-scm.com/download/win) 后在「设置 → 数据 → 重试」即可恢复。
- 恢复旧版本：在数据目录执行 `git log --oneline` 看历史、`git checkout <提交> -- <文件>` 找回内容。
  不熟悉 git 也没关系——手动复制整个目录同样有效。

## 4. 用 Obsidian 等外部工具打开数据目录（并发规则）

种子阶段我们希望用 Obsidian **检查格式与浏览**，请注意：

- 尽量**不要在 ResearchThread 开着的同时用外部工具编辑同一批文件**；需要改，先关掉一边。
- 如果两边同时改了：ResearchThread 保存时会弹出「文件已被外部修改」的提示，由你选择
  「覆盖保存」「重新加载」还是「取消」，**不会静默覆盖**。
- 关闭应用时若有未保存的编辑（任务 / 项目上下文 / 周文档草稿），会先询问你是否放弃。

## 5. 隐私说明（请务必读一遍）

- 应用**不联网、不上传任何数据**：没有账号、没有遥测、没有崩溃上报。所有内容只存在于你的电脑。
- 唯一例外是你主动在底部终端里运行外部 CLI agent（如 `claude`、`codex`）：这些工具由各自的服务提供，
  你发给它们的内容会按 **该服务自己的条款** 离开本机。不运行就不会发送。
- **反馈时请不要把整个数据目录打包发给我们。** 数据目录包含你的任务正文、上下文日志、
  周报、活动时间线和 git 历史（含已删除内容的历史版本），这些是你的科研记录，我们不需要也不想要。

## 6. 反馈方式与脱敏模板

请把下面这份模板填好发回（能复制粘贴的文字即可，不要截图正文内容）：

```
【环境】
应用版本：设置 → 关于（如 0.1.0 种子测试版）
Windows 版本：如 Win10 22H2 / Win11 23H2
安装方式：全新安装 / 覆盖安装 / 升级
是否安装 git：是 / 否
是否用过 Obsidian 打开数据目录：是 / 否

【问题】
发生了什么：（操作步骤 1. 2. 3.）
期望是什么：
是否可复现：每次 / 偶尔 / 仅一次
报错文字：（如有，照抄弹出的错误信息，不含你的笔记内容）

【可选：脱敏计数】（愿意的话填）
空间数 / 项目数 / 任务数：如 2 / 6 / 23
最常用操作 Top3：如 改状态、追加上下文、收件箱
```

- 统计数字在应用里可以数出来（侧栏可以数项目和任务）。
- 涉及具体某条任务的问题，可以把它**改写脱敏**后再描述（例如「一个 doing 状态、带☆、next 里有中文分号的任务」）。
- 第 10 天与第 4 周的访谈会单独约时间，访谈只问「你多久能回到工作现场」，不会要求导出任何文件。

## 7. 已知限制（种子版）

- 仅 Windows x64；macOS、自动更新、安装包签名在后续版本。
- 周文档为实验功能：同一周「重新生成」会覆盖手工修改（有二次确认，git 历史可找回）。
- 图谱视图与整体目标冲突，保持禁用；Agent 面板是占位，尚未接真实 CLI。

遇到任何「数据看起来不对」的情况，请先复制整个数据目录留证，再联系我们。谢谢！
