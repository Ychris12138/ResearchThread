ResearchThread 种子测试版 安装须知
====================================

感谢试用 ResearchThread（种子测试版）。

安装前请了解：

1. 本安装包未做代码签名。双击后若 Windows SmartScreen 弹出
   「Windows 已保护你的电脑」，属预期提示：请点「更多信息」→
   「仍要运行」。不需要关闭 SmartScreen。

2. 安装为「按用户安装」，不需要管理员权限；程序装在
   %LOCALAPPDATA%\ResearchThread。

3. 你的全部笔记数据以 Markdown 文件保存在
   C:\Users\<你的用户名>\ResearchThread\（数据目录），
   与程序分离。卸载应用不会删除数据目录。

4. 应用本身不联网、不上传任何数据。数据目录每天第一次启动会
   自动做一次 git 快照（版本保护）；未安装 git 的电脑会在界面
   显示「快照保护未生效」警告，数据仍正常保存。

5. 建议安装后核对下载页公布的 SHA-256 校验值：
   PowerShell 执行 Get-FileHash 对比安装包哈希。

6. 使用问题请按《种子测试手册》中的脱敏反馈模板反馈；
   请勿把整个数据目录打包发送。

按「我同意」继续安装。
